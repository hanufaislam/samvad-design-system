# Third-party assets

- Phosphor icon SVGs: retain the upstream MIT notice in
  `website/public/icons/LICENSE` and `design-system/foundations/assets/icons/LICENSE`.
- Geist and Geist Mono: installed from the pinned Fontsource packages. The
  original SIL Open Font License notices are copied unchanged into
  `website/public/licenses/geist-OFL.txt` and `geist-mono-OFL.txt` so the production
  build carries them alongside generated font assets.
- Astro, Pagefind, Fontsource and development dependencies retain their upstream
  package licenses. The npm lockfile records exact dependency versions.

These notices do not select a license for Samvad's own code, documentation or
brand assets. That choice remains a release decision for the project owner.
