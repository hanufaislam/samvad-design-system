# Samvad documentation website

The Astro application lives here; the repository root also supplies foundation
and token inputs. Do not publish this directory alone as source.

- 84 static routes across six approved sections.
- 49 component families and the 629-token system.
- Existing responsive shell, accessible native controls, local fonts/icons,
  full-text Pagefind production search, theme switching and copy helpers.

From this directory: `npm ci`, `npm run dev`, or `npm run check && npm run build &&
npm run verify && npm run preview -- --port 4321`.

See [the root README](../README.md) for installation/toolchain, architecture,
validation and licensing; [publishing preparation](../publishing/README.md) for
root/project-base builds and the inactive GitHub Pages workflow template.
