# Spacing

Base rhythm: 4 logical units, with 2 for optical adjustments.

| Name | Value |
| --- | --- |
| space/0 | 0 |
| space/2 | 2 |
| space/4 | 4 |
| space/8 | 8 |
| space/12 | 12 |
| space/16 | 16 |
| space/20 | 20 |
| space/24 | 24 |
| space/32 | 32 |
| space/40 | 40 |
| space/48 | 48 |
| space/64 | 64 |
| space/80 | 80 |
| space/96 | 96 |

2–8: tight detail; 12–24: related controls/content; 32–48: section separation; 64–96: large compositions. Zero is an intentional absence of space. Do not render a zero-width specimen as a nonzero spacing value. Hit targets are independent of icon and visible shape size. Use logical start/end for localizable padding.
