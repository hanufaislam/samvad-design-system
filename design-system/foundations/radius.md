# Radius

| Name | Value |
| --- | --- |
| none | 0 |
| xs | 2 |
| sm | 4 |
| md | 8 |
| lg | 12 |
| xl | 20 |
| full | 9999 |

Use md for routine controls, lg/xl for larger surfaces, full for circles/capsules. Figma/web may use 9999 clamped to half the smaller dimension; native platforms should use a capsule shape or equivalent clamping. Do not treat 9999 as a physical mobile radius. Keep nested radii visually coherent and avoid pill shapes on all surfaces.
